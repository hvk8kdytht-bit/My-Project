结论

CoTracker3 的价值

  • 2D 跟踪能力强 — 87% 的可见点始终在物体内，适合做滑移检测（判断点是否偏离物体）
  • 长时序优势 — 整段视频联合优化，比帧间光流法更稳定
  • 抗遮挡 — Transformer 架构能在遮挡后恢复跟踪
  • 速度估计受限 — 在 YCB-Video 噪声深度图上速度误差仍大（2.17 m/s），但在高质量深度图场景下潜力很大
  • GPU 加速空间大 — CPU 10s/场景，GPU 可降至 1s 以内

推荐使用场景

  • 滑移检测 — 跟踪夹爪点 vs 物体点的相对运动，X/Y 方向精度足够
  • 物体跟踪 — 87% 精度足以判断物体是否在夹爪内
  • 速度估计 — 需要高质量深度图配合，或改用 2D 像素速度（不转 3D）
